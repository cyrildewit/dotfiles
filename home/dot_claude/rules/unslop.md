## Unslop

- Always apply the `unslop` skill to any prose you write: documentation, README content, commit messages, PR descriptions, reports, summaries, chat responses, and any other user-facing text. Invoke the Skill tool with `unslop` before writing the text, then follow its guidance.
- This also applies when editing or reviewing existing prose, and to short pieces of text. Do not skip it because the text seems too small to matter.
